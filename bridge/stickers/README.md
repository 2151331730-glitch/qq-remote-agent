# 表情库

把表情图片直接丢进这个目录（`.gif` / `.png` / `.jpg` / `.jpeg` / `.webp`）。

**文件名就是它的名字**：

```
猫猫震惊.gif      →  "猫猫震惊"
无语.png          →  "无语"
```

机器人回复时会在末尾写 `@@表情:猫猫震惊@@`，bridge 把它摘掉、单独发一张，
发送时图片段带 `sub_type: 1` —— QQ 里显示成「表情」，不是撑满气泡的大图。

## 想改描述

可选：建一个 `index.json`，给表情加更像人话的描述（提示词里给模型看的就是描述）。

```json
{
  "猫猫震惊": { "file": "cat.gif", "desc": "愣住了" },
  "无语":     { "file": "wu.png", "desc": "懒得说话" }
}
```

## 注意

- 提示词里最多列 20 张，按文件名排序。表情多了就把最常用的改成 01_xxx.gif 这种前缀。
- 单张别超过 1MB，gif 太大发出去会慢。
- 这个目录里的图片不入库（`.gitignore` 里只放行本文件）。
- 改了文件不用重启：每次回话前会重新读一遍清单。
